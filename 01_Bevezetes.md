# Bevezetés

## Chocolatey

Telepítse a Chocolatey csomagkezelőt. Továbbiakban ezt a csomagkezelőt használjuk.

A csomagkezelő weboldala:

* [https://chocolatey.org/](https://chocolatey.org/)

Bővebb leírása:

* [https://szit.hu/](https://szit.hu/)

## Telepítések

A szoftverek telepítése choco paranccsal:

```bash
choco install vscode
choco install nodejs
choco install dia
choco install composer
choco install insomnia-rest-api-client
choco install gimp
choco install totalcommander
choco install xampp-81
choco install git

## Resen telepítése

```bash
npm install --global resen
```

## Angular telepítése

```bash
npm install --global @angular/cli@22.1.5
```
